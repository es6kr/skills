## Quality and Anti-Hallucination Discipline

1. **Evidence-First**:
   - Never assume an edit succeeds without running verification commands.
2. **Grounded in Existing Patterns**:
   - Follow existing conventions in the repository rather than inventing novel patterns.
3. **Encoding & BOM Preservation**:
   - Preserve Byte Order Marks on UTF-8 files.
4. **GUARD Comments**:
   - Add explicit `// GUARD:` comments on safety-critical constraints.
