# Task Plan (`/task-plan`)

Comprehensive planning and research skill for software engineering and organizational tasks.

## Topics

- **`pre-search`** (`pre-search.md`): Mandatory pre-creation RAG, Qdrant vector search, and wiki pre-lookup gate.
- **`research`** (`research.md`): Deep technical research, codebase exploration, and alternative analysis.
- **`plan`** (`plan.md`): 3-tier deliverable hierarchy (`roadmap-*.md`, `plan-*.md` parent, `plan-*.md` sub-plan) with 8 mandatory sections and Plane short Browse URLs.
- **`plan-guard`** (`plan-guard.md`): Always-on comment cycle, ambiguity detection, and trade-off ask loop.
- **`proposal`** (`proposal.md`): Formal business proposal, requisition, and decision document support.
- **`artifact-rules`** (`artifact-rules.md`): Volatile brain session staging, naming rules, and canonical migration.
- **`review`** (`review.md`): Mandatory User Review Gate (`AskUserQuestion`) and git worktree isolation.
